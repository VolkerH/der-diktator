      Keyboard shortcuts

      Tab and Shift+Tab reach every control. Enter or Space activates buttons. Arrow keys operate native choices. Escape closes dialogs and the mobile sidebar. In the chat list, Up/Down moves between visible chats; Enter opens the focused chat.

      Ctrl means the Control key on every platform, including macOS. Type Ctrl+Shift+ a digit, ArrowUp or ArrowDown. Leave blank to disable an action. Each binding must be unique. Browser and text editing shortcuts are reserved. Shortcuts pause while a dialog is open. Arrow shortcuts also pause in text fields to preserve selection.
